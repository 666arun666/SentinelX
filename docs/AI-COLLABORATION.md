# AI Collaboration Rules

1. **Follow the Architecture and Roadmap exactly.**
2. **Build M1-M9 sequentially.** Do not skip ahead.
3. **No hallucinated external APIs.** If an API key isn't provided, use mocks for tests but build the real integration code.
4. **No unauthorized architectural changes.** If a change is needed, propose it and wait for explicit approval.
5. **Report Milestone Completion:** Upon completing a milestone, state what was done and await authorization before proceeding to the next.
